## 🛠️ Prérequis techniques

| Outil | Version | Vérification |
|---|---|---|
| PHP | 8.1+ (testé 8.3) | `php -v` |
| Extension PHP `pgsql` | Installée et activée | `php -m \| grep pgsql` |
| Extension PHP `pdo_pgsql` | Installée et activée | idem |
| PostgreSQL | 14+ | `psql --version` |
| Composer | 2.x | `composer --version` |
| Node.js | 18+ (testé 20) | `node -v` |
| npm | 9+ (testé 10) | `npm -v` |

### ⚠️ Piège connu : versions PHP multiples

Si tu as plusieurs versions de PHP installées (ex. `php8.3` + `php8.4`), l'extension `pgsql` doit être installée **pour la version exacte que tu exécutes** :

```bash
php -v                                    # → note la version, ex : 8.3.31
sudo apt install php8.3-pgsql             # → adapter à ta version
php -m | grep -i pgsql                    # → doit afficher `pgsql` et `pdo_pgsql` sans warning
```

### ⚠️ Piège connu : charset PostgreSQL

Dans `app/Config/Database.php` **et** dans `.env`, le charset doit être `UTF8` (pas `utf8mb4` qui est MySQL) :

```php
'charset'  => 'UTF8',      // ✅
'DBCollat' => '',          // ✅ (vide pour PostgreSQL)
```

Sinon : `ERROR: invalid value for parameter "client_encoding": "utf8mb4"`.

## 📦 Installation

### 1. Cloner le projet et installer les dépendances

```bash
git clone <repo-url> SIRH
cd SIRH
composer install
npm install
```

### 2. Créer la base de données

```bash
sudo -u postgres psql
```

Puis dans psql :

```sql
CREATE DATABASE recrutement_rh;
\q
```

### 3. Exécuter le script de création

```bash
psql -U postgres -d recrutement_rh -f "Base de données recrutement et gestion RH.txt"
```

> ⚠️ **Vérifie que `historique_contrat` a bien été créée** (bug connu du script initial) :
> ```sql
> \dt historique_contrat
> ```
> Si elle manque :
> ```sql
> CREATE TABLE historique_contrat (
>     id_historique BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
>     id_contrat BIGINT NOT NULL REFERENCES contrat(id_contrat) ON DELETE CASCADE,
>     ancien_statut VARCHAR(30),
>     nouveau_statut VARCHAR(30) NOT NULL,
>     id_utilisateur BIGINT REFERENCES utilisateur(id_utilisateur),
>     commentaire TEXT,
>     date_action TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
> );
> ```

### 4. Configurer `.env` (ou `app/Config/Database.php`)

```ini
CI_ENVIRONMENT = development

app.baseURL = 'http://localhost:8080/'

database.default.hostname = localhost
database.default.database = recrutement_rh
database.default.username = postgres
database.default.password = <TON_MOT_DE_PASSE>
database.default.DBDriver = Postgre
database.default.charset  = UTF8
database.default.port     = 5432
```

### 5. Installer DomPDF (pour la génération PDF contrat)

```bash
composer require dompdf/dompdf
```

### 6. Build Vue

```bash
npm run build
```

**Attendu** : 9 fichiers JS générés dans `public/assets/js/` :

```

dashboard-candidat.js
notifications-candidat.js
offres-candidat.js
candidatures-direction.js
offres-direction.js
mes-candidatures-candidat.js
requetes-candidat.js
contrats-candidat.js
chunks/
```

## 🐛 Troubleshooting

| Problème | Cause | Solution |
|---|---|---|
| `Call to undefined function pg_connect()` | Extension `pgsql` absente | `sudo apt install php8.X-pgsql` (version exacte de `php -v`), puis redémarrer `php spark serve` |
| `invalid value for parameter "client_encoding": "utf8mb4"` | charset MySQL dans config | Remplacer `utf8mb4` par `UTF8` dans `Database.php` **et** `.env` |
| `"session" filter must have a matching alias defined` | Filtre `session` dans `$globals['before']` | Retirer `'session',` de `Filters.php` |
| `Undefined property: CandidaturesController::$db` | Controller n'a pas `$db` | Ajouter `protected $db;` + `initController()` avec `$this->db = \Config\Database::connect();` |
| `relation "historique_contrat" does not exist` | Table manquante | Créer via `CREATE TABLE historique_contrat (...)` (voir Bloc 1 installation) |
| `duplicate key value violates unique constraint "offre_emploi_id_demande_key"` | Contrainte `UNIQUE` sur `id_demande` | Chaque offre doit avoir sa propre demande (créer 1 demande par offre) |
| `ENAMETOOLONG: name too long` au `npm run build` | Vite copie `public/` dans `outDir` récursivement | Dans `vite.config.js` : `publicDir: false`, `emptyOutDir: true` |
| `Failed to load module script` | Mauvais MIME type sur `.js` | `curl -I http://localhost:8080/assets/js/dashboard-direction.js` → doit renvoyer `Content-Type: text/javascript` |
| Page blanche sur composant Vue | JS non chargé | F12 Network → vérifier que `dashboard-xxx.js` est en 200 |
| `401` sur `/api/...` | Session expirée | Se reconnecter via `/dev/login-as/...` |
| PDF vide (0 octet) | Le seed contient `%PDF-1.4` uniquement (8 octets) | Normal — c'est un faux PDF de test. Remplacer par un vrai si besoin : voir section « Fix PDF » plus bas |

### Fix PDF — insérer un vrai PDF de test

```bash
wget -O /tmp/dummy.pdf https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf

psql -U postgres -d recrutement_rh -c "
UPDATE candidature
SET cv_donnees = pg_read_binary_file('/tmp/dummy.pdf'),
    lettre_donnees = pg_read_binary_file('/tmp/dummy.pdf'),
    cin_donnees = pg_read_binary_file('/tmp/dummy.pdf')
WHERE id_candidature IN (1,2,3);

SELECT id_candidature, length(cv_donnees) FROM candidature;
"
```

## 📚 Règles de gestion appliquées (extraits)

| Règle | Implémentation |
|---|---|
| **RG-CAND-002** — 1 candidature par offre | Contrainte `UNIQUE(id_offre, id_candidat)` + vérification serveur |
| **RG-CAND-003/004** — CV PDF + Lettre PDF + CIN PDF/Image | Validation `finfo` (MIME réel) + `max_size` 5 Mo |
| **RG-CAND-005** — statut initial `RECUE` | Constante SQL par défaut |
| **RG-CAND-007** — historique obligatoire | `historique_candidature` à chaque transition |
| **RG-NOTIF-001/004** — notification de retenue | Création auto dans `retenir()` + contrôle `id_utilisateur` |
| **RG-REQ-002/003** — multi-conditions, champ vide = pas de requête | Traitement en boucle sur `$_POST['proposition']` |
| **RG-CONTRAT-006** — PDF généré après acceptation | DomPDF + `contrat.pdf_donnees` (BYTEA) |
| **RG-CONTRAT-009/010/011/012** — employé créé après signature | Transaction : `contrat` + `employe` + `affectation` + `historique_*` |
| **RG-HIST-001/004** — historique transactionnel | Toutes les transitions sont dans `transBegin()...transCommit()` |
